NPF-Q400 — HISTORIQUE CUMULATIF DES MODIFICATIONS

v13.91 TEST — alerte post-MAJ fiable / fenêtre FUEL MINI séparée en Dérout. / GAAR

Modifications apportées :
- correction du message « Mise à jour installée » afin qu’une navigation automatique très rapide ne puisse plus consommer l’alerte avant qu’elle ait été réellement visible ;
- le marqueur de demande de relance n’est désormais validé qu’après 2 secondes de visibilité continue de la fenêtre ;
- si le service worker recharge la page avant ce délai, le marqueur reste actif et la fenêtre réapparaît sur la page stable ;
- fenêtre de relance placée au-dessus de l’écran de démarrage afin d’être visible dès son insertion ;
- lors de la navigation forcée suivant l’activation d’un nouveau service worker, attente prioritaire du nouvel index jusqu’à 5 secondes avant recours au cache ;
- conservation du secours rapide existant pour les lancements ordinaires et du fonctionnement hors ligne ;
- dans l’onglet « DEROUT. / GAAR », déplacement des deux lignes « Fuel mini 1 Lrg / BASE » et « Fuel mini 1 Lrg / Pélic » hors de la fenêtre de droite ;
- création d’une fenêtre indépendante intitulée « FUEL MINI » dans la colonne gauche ;
- placement de cette fenêtre immédiatement au-dessus de « Nbr Rotations Possibles » ;
- conservation des valeurs, aides « ? », formules et identifiants existants : seuls leur conteneur et leur position sont modifiés ;
- adaptation de la colonne gauche pour conserver l’ensemble dans la hauteur disponible sans ajouter de défilement ;
- aucune modification des calculs, des autres onglets, des tailles de police ou des données enregistrées ;
- version applicative portée en v13.91 TEST.

v13.90 TEST — cellule RLT : unité en fond et effacement direct

Modifications apportées :

- suppression du comportement nécessitant auparavant un premier appui pour retirer seulement « kg », puis un second pour vider la cellule ;
- interception de l’appui avant la prise de focus du champ afin de garantir le fonctionnement sur iPad/PWA ;
- aucune modification des calculs, de l’enregistrement par vol, de l’export PDF, des autres cellules ni de la mise en page ;
- version applicative portée en v13.90 TEST.

v13.89 TEST — corrections RLT / espacement Suivi rotations / alerte post-MAJ immédiate

Modifications apportées :
- dans l’onglet « BLOC / FUEL », correction du chevauchement entre le premier chiffre de la cellule « RLT » et la croix d’effacement lorsqu’une valeur à quatre chiffres telle que 9000 est saisie ;

- conservation du nombre d’affichages et de tous les autres mécanismes de mise à jour existants ;

v13.88 TEST — Fuel sur feu Prévi non modifiable / RLT départ / espacements des fenêtres droites

Modifications apportées :
- dans l’onglet « PREVI. NBR ROTATIONS », suppression de toute possibilité de modifier « Fuel sur Feu » ;
- suppression du bouton AUTO/MANUEL et du champ de saisie associé ;
- « Fuel sur Feu » est désormais une valeur strictement calculée en lecture seule à partir de « FUEL Départ - Conso transit Base → Feu » ;
- adaptation de l’aide « ? » pour préciser que cette valeur est automatique et non modifiable ;
- dans l’onglet « BLOC / FUEL », ajout d’une cellule « RLT » entre « FUEL Départ » et « Base » ;
- cette cellule permet de saisir la masse de retardant présente dans l’avion, en kilogrammes ;
- valeur RLT enregistrée séparément pour chaque vol et restaurée lors du changement de vol ;
- ajout de la valeur RLT dans l’en-tête de chaque vol de l’export PDF / aperçu imprimable ;
- ajout de la valeur RLT dans l’export PDF de secours en texte ;
- dans l’onglet « SUIVI ROTATIONS », la fenêtre de droite reprend le même espacement entre les lignes que la fenêtre de droite de « PREVI. NBR ROTATIONS » ;
- dans l’onglet « DEROUT. / GAAR », augmentation automatique de l’espace entre toutes les lignes de la fenêtre de droite en répartissant le contenu sur la hauteur disponible ;
- cette répartition dynamique évite d’ajouter un défilement vertical ;
- calculs de rotations, valeurs BINGO, tailles de police et autres fonctions laissés inchangés ;
- version applicative portée en v13.88 TEST.

v13.87 TEST — aides détaillées Suivi rotations / Dérout. GAAR

Modifications apportées :

- dans l’onglet « SUIVI ROTATIONS », ajout d’une aide « ? » pour « Conso Rotation » ;
- les aides de Suivi rotations détaillent la source retenue, les distances, les forfaits, les vitesses, les consommations, les formules et le mode AUTO/MANUEL lorsqu’il existe ;
- dans l’onglet « DEROUT. / GAAR », ajout d’une aide « ? » pour « Durée Rotation » ;
- dans l’onglet « DEROUT. / GAAR », ajout d’une aide « ? » pour « Conso Rotation » ;
- les aides de Dérout. / GAAR indiquent explicitement si la case « Retour Pélic avant feu » est cochée ou non ;

- les aides précisent que ce choix modifie le trajet initial, mais pas les valeurs des rotations suivantes Feu ↔ Pélic ;
