NPF-Q400 TEST v13.70 — Import ZIP / reset profond iPad

Base : v13.69, elle-même basée sur v13.68 et sur la fluidité validée v13.58.

Corrections :
- nouvelle base IndexedDB de tuiles : OfflineTilesDB_v13_70_clean ;
- l’ancienne base v12_21 n’est plus réutilisée après mise à jour ;
- ajout d’un vrai reset profond des cartes offline ;
- le reset profond ferme la connexion IndexedDB de la page ;
- le reset profond demande au service worker de libérer sa connexion IndexedDB ;
- le reset profond désinscrit temporairement le service worker puis recharge l’app pour le réinstaller proprement ;
- suppression tentée de toutes les bases OfflineTilesDB connues ;
- ajout d’un handler onversionchange sur IndexedDB pour fermer proprement la base si Safari demande une suppression/changement de version ;
- le bouton de maintenance devient Réinitialiser profond.

Objectif : éviter le blocage d’import à 31 tuiles ou 171 tuiles qui ne se corrigeait qu’en supprimant complètement la PWA.

Procédure de test conseillée :
1. Installer v13.70.
2. Ouvrir Gestion des Cartes > Maintenance / dépannage.
3. Cliquer Réinitialiser profond.
4. Laisser l’app se recharger.
5. Importer les ZIP de la carte France dans l’ordre.
6. Importer l’OACI après la carte France.

Limite connue : si iPadOS/Safari refuse encore de libérer le quota du site malgré le reset profond, le dernier recours reste la suppression de la PWA. Mais la v13.70 évite de réutiliser la base verrouillée actuelle.
