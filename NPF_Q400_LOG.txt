NPF-Q400 TEST v13.69 — Import ZIP stable iPad après utilisation d'une carte

Base : v13.68 Fréquences OPS icône parabole.
Référence fluidité conservée : v13.58.

Corrections principales :
- Correction du blocage d'import ZIP après utilisation d'une carte offline active.
- Suspension renforcée de la carte offline avant import : plus seulement visuelle/localStorage, mais aussi persistée dans IndexedDB/settings.
- Le service worker répond maintenant par accusé de réception avant que la page commence à écrire dans IndexedDB.
- Pendant l'import, le service worker vide le cache mémoire des tuiles, désactive les packs actifs et ferme réellement sa connexion IndexedDB.
- Profil d'import sécurisé pour les ZIP multi-blocs non volumineux contenant beaucoup de tuiles, typiquement les blocs à ~20 000 / 25 000 tuiles.
- Réduction des lots IndexedDB pour ces ZIP : écriture en lots de 40 tuiles au lieu de gros lots pouvant bloquer Safari/iPadOS.
- Réouverture périodique de la base toutes les 400 tuiles sur ces imports sécurisés.
- Détection d'une transaction IndexedDB bloquée : timeout, abort, réouverture de la base, puis reprise automatique en micro-lots.
- Messages d'import plus explicites : "Import sécurisé iPad".
- Restauration propre de l'état offline précédent si l'import échoue.

Ce qui est conservé :
- v13.68 : bouton Fréquences OPS avec icône parabole.
- v13.67 : import Carte Fréquences OPS / Doc FDF Réduité.
- v13.66 : PDF Pélic + Doc PDF Réduite commune.
- v13.65 : clic point GAAR hors modification = petite étiquette seule.
- Corrections GAAR v13.59 à v13.64.
- Fluidité carte validée v13.58.

Mode de test recommandé :
1. Installer v13.69.
2. Relancer l'app si le message de mise à jour le demande.
3. Utiliser une carte offline déjà installée.
4. Revenir dans Téléchargement cartes.
5. Importer le ZIP suivant.
6. Le compteur ne doit plus rester bloqué vers 171 / 22387.

Remarque :
L'import sera probablement un peu plus lent sur les gros blocs de tuiles, mais il doit être beaucoup plus stable sur iPad.
