NPF-Q400 — Version TEST v13.45

Base : v13.44 TEST, issue de v13.43 / v2026.55.

Objet : remplacement du téléchargement PMTiles par un import local manuel depuis l’iPad.

Modifications principales :
- Suppression de l’URL serveur centralisée PMTILES_FRANCE_SUD_BASE_URL.
- Ajout d’un bouton “Importer la carte locale”.
- Ajout d’un sélecteur de fichiers multiple pour sélectionner en une seule fois :
  - manifest.json
  - NPF-France-Sud-z14.pmtiles.part001 à part007
- Le manifeste est lu localement depuis le fichier sélectionné.
- Chaque bloc est lu depuis le fichier local correspondant, un par un.
- Contrôle conservé :
  - validité du manifest.json ;
  - espace disponible via navigator.storage.estimate() ;
  - demande de stockage persistant via navigator.storage.persist() ;
  - taille de chaque bloc ;
  - SHA-256 de chaque bloc via crypto.subtle.digest('SHA-256', ...) ;
  - stockage séparé en IndexedDB NPF_PMTiles_DB ;
  - reprise en conservant les blocs déjà validés.
- Le bouton “Reprendre l’import” rouvre le sélecteur de fichiers : il faut resélectionner manifest.json + les 7 blocs, mais les blocs déjà validés ne sont pas réimportés.
- Aucune dépendance à un serveur pour installer la carte.
- Aucune URL CDN ajoutée.
- Les blocs PMTiles restent en IndexedDB, jamais dans localStorage ni dans le Cache Storage du service worker.
- La base raster OfflineTilesDB_v12_21 n’est pas modifiée.
- La logique des packs ZIP raster existants reste inchangée.

Service worker :
